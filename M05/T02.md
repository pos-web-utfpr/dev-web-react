# Desenvolvimento de Aplicações Web Dinâmicas e Interativas

## Módulo 5: Boas Práticas e Testes Automatizados

**Objetivo de Aprendizagem**: Aprimorar a qualidade do código e garantir a confiabilidade através da adoção de boas práticas de desenvolvimento e testes automatizados.

## Tópico 2: Testes Unitários

- O que são testes unitários?
- Configuração Vitest
  - `yarn add -D vitest jsdom @testing-library/react @testing-library/jest-dom @testing-library/user-event`
  - Criação dos scripts no `package.json`
- Testes de funções, exemplo com helper `formatters.ts`
- Testes de componentes, exemplo com componente `ProductDetailsCard`:
  - Teste de renderização, garantir que todas as props sejam utilizadas corretamente
  - Teste de eventos, garantir que os eventos sejam disparados corretamente (mock de funções)
  - Teste de navegação, garantir que todos os links sejam clicáveis e naveguem para as páginas corretas (mock de navegação)
- Testes de hooks, exemplo com hook `useAsyncData`:
  - Teste de estado inicial (loading em true, data e error em null)
  - Teste de sucesso (loading em false, data com o resultado e error em null)
  - Teste de erro (loading em false, data em null e error com a mensagem de erro)
  - Teste de refetch (chamada da função refetch re-executa a asyncFn)

## Prompts da Aula

1. **Instalação e Configuração do Vitest:**

```markdown
Instale o Vitest, jsdom, @testing-library/react, @testing-library/jest-dom e @testing-library/user-event no projeto. Configure o `vite.config.ts`, adicione os scripts no `package.json` e crie o arquivo de setup.
```

2. **Testes de Funções (`formatters.ts`):**

```markdown
Crie uma suíte de testes unitários com Vitest para o arquivo `src/helpers/formatters.ts`. Cubra os cenários de formatação das funções `formatCurrency` e `formatStock`.
```

3. **Testes de Componentes (`ProductDetailsCard`):**

```markdown
Crie testes unitários com Vitest e React Testing Library para o componente `ProductDetailsCard`. Valide a renderização das props do produto, o disparo dos eventos dos botões e o link de navegação.
```

4. **Testes de Hooks (`useAsyncData`):**

```markdown
Crie testes unitários com Vitest para o custom hook `useAsyncData`. Teste os estados de carregamento inicial, resolução de sucesso, tratamento de erro e a re-execução com a função `refetch`.
```

5. **Testes para a Aplicação Inteira:**

```markdown
Crie testes unitários com Vitest cobrindo os principais componentes, hooks e helpers de toda a aplicação.
```
