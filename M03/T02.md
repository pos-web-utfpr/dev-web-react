# Desenvolvimento de Aplicações Web Dinâmicas e Interativas

## Módulo 3: Navegação e Interface Gráfica do Usuário

**Objetivo de Aprendizagem**: Criar aplicações multi-página com navegação fluida e interfaces profissionais sem reinventar a roda.

## Tópico 2: Mantine UI: Fundamentos e Componentes Essenciais

- Introdução ao Mantine UI
- Instalação e configuração do Mantine UI
- Theming global, cores e estilos
- Layouts, Container, Stacks, Groups e Grid responsiva
- Componentes essenciais: Button, Card, Modal, Badge, Loader

### Prompt 1: Refatoração da Aplicação com Mantine UI

```markdown
Vamos PLANEJAR a refatoração do nosso projeto de Gestão de Supermercado (ServeRest UI).

Atue como um desenvolvedor Front-end especialista em React e Mantine UI na sua versão mais recente (latest). Preciso que você refatore a aplicação criada anteriormente (que possuía apenas HTML semântico puro e React Router) adicionando uma interface de usuário moderna, responsiva e elegante com Mantine UI.

Você deve seguir as diretrizes de estilo definidas em: `anexos/ui-skill.md`

Requisitos:

1. Instale as bibliotecas necessárias:
   - `@mantine/core`
   - `@mantine/hooks`
   - `@mantine/form`
   - `@mantine/notifications`
   - `@mantine/dates`
   - `@mantine/modals`
   - `@tabler/icons-react`.
2. Configure o import do CSS do Mantine e o Provider padrão.
3. Refatore os Layouts (`RootLayout`, `AuthLayout`) e as Páginas (`Home`, `Dashboard`, `Produtos`, `ProdutoDetalhes`, `Login`) utilizando componentes do Mantine (como `AppShell`, `Container`, `SimpleGrid`, `Card`, `Button`, `Title`, `Text`, `Badge`, `Loader`, `TextInput`, `PasswordInput`) e ícones do `@tabler/icons-react`.

```
