# Desenvolvimento de Aplicações Web Dinâmicas e Interativas

## Módulo 3: Navegação e Interface Gráfica do Usuário

**Objetivo de Aprendizagem**: Criar aplicações multi-página com navegação fluida e interfaces profissionais sem reinventar a roda.

## Tópico 3: Mantine UI: Formulários, Tabelas e Feedback ao Usuário

- @mantine/form para validação e controle de formulários
- Table com paginação e ordenação
- Notifications e LoadingOverlay para feedback visual
- @mantine/dates para campos de data

### Prompt 1: Formulário de Login com Validação e Feedback

```markdown
Vamos aprimorar a página de Login e o formulário de cadastro de produtos.

Você deve seguir as diretrizes de estilo definidas em: `anexos/ui-skill.md`

Requisitos:

1. Implemente o `@mantine/form` no componente de Login para controlar o estado e a validação do formulário.
2. Adicione validações em tempo real (onBlur) para os campos de email e senha.
3. Exiba mensagens de erro claras abaixo de cada campo em caso de falha na validação.
```

### Prompt 2: Tabela de Produtos com Paginação e Ordenação

```markdown
Vamos substituir a lista de produtos atual por uma Tabela responsiva e interativa. Os produtos atuais (listados como Cards dentro do Grid), devem permanecer na tela, mas como uma seção "Produtos em Destaque", assim não perdemos o exemplo do Grid.

O mock de produtos precisa ser alterado para que a tabela funcione com paginação, então adicione mais produtos, no mínimo 100. E mantenha a quantidade padrão de 10 produtos por página.

Vamos simular o loading da tabela com overlay, para isso, use um timeout de 2s.

Você deve seguir as diretrizes de estilo definidas em: `anexos/ui-skill.md`

Requisitos:

1. Utilize o componente `Table` do Mantine para exibir a lista de produtos.
2. Adicione funcionalidade de ordenação (sorting) clicando nos títulos das colunas.
3. Implemente paginação (Pagination) com controle de registros por página.
4. Utilize `LoadingOverlay` enquanto os dados estão sendo carregados.
5. Mantenha o tema de cores definido em `anexos/mantine-theme.ts`.
```

### Prompt 3: Painel de Vendas com @mantine/dates e @mantine/charts

```markdown
Vamos implementar um gráfico interativo de relatórios no Dashboard.

Você deve seguir as diretrizes de estilo definidas em: `anexos/ui-skill.md`

Requisitos:

1. Instale a biblioteca `@mantine/charts` e sua dependência `recharts`.
2. Crie um mock de histórico de vendas (`mockCarrinhos`) alinhado com o padrão de resposta de carrinhos da API ServeRest, contendo datas e valores.
3. No Dashboard, adicione o componente `DatePickerInput` (com `type="range"`) do `@mantine/dates` para seleção do intervalo de datas.
4. Exiba um gráfico (`AreaChart` ou `BarChart` do `@mantine/charts`) exibindo o faturamento diário, filtrado dinamicamente pelo período selecionado.
```
