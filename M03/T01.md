# Desenvolvimento de Aplicações Web Dinâmicas e Interativas

## Módulo 3: Navegação e Interface Gráfica do Usuário

**Objetivo de Aprendizagem**: Criar aplicações multi-página com navegação fluida e interfaces profissionais sem reinventar a roda.

## Tópico 1: React Router: Navegação em SPAs

- Instalação e configuração do react-router-dom
- BrowserRouter, Routes, Route, Link, NavLink
- Rotas dinâmicas e parâmetros de URL (useParams)
- Navegação programática (useNavigate)
- Layouts com Outlet

Vamos estudar isso na prática! Nosso objetivo é simular o frontend de um "Sistema Gestão de Supermercado" (versão mini!).

### Estrutura de Rotas

```text
/ (Pública - Landing Page do ERP)
└── / (Home)

/login (Pública Minimalista - AuthLayout sem Header/Nav)
└── /login (Login)

/app (User Space ERP - Área Privada protegida por ProtectedRoute via Outlet)
└── (RootLayout com Shell, Header e Nav Interna)
    ├── /app (Dashboard - Painel Inicial do Usuário)
    ├── /app/produtos (Produtos - Lista de Produtos)
    └── /app/produtos/:id (ProdutoDetalhes - Detalhes do Produto)

* (NotFound - Página 404)
```

### Prompt

```markdown
Vamos PLANEJAR uma tarefa.

Atue como um desenvolvedor Front-end especialista em React. Preciso que você crie a estrutura completa de arquivos e código para uma aplicação React utilizando o `react-router` no modo declarativo.

O objetivo desta aplicação é servir como base para a construção do front-end da API ServeRest (e-commerce/gestão). Por enquanto, usaremos dados mockados compatíveis com o schema real da ServeRest.

IMPORTANTE: NÃO inclua nenhum tipo de estilização ou CSS (sem styled-components, sem CSS Modules, sem classes de frameworks e SEM inline styles). Use apenas HTML semântico puro para os componentes, pois a estilização será adicionada futuramente com uma biblioteca de UI.

Requisitos e Estrutura de Arquivos a criar:

1. `src/mocks/serveRestMocks.js`
   - Exporte um array `mockProdutos` contendo pelo menos 2 produtos no formato exato da API ServeRest (com as chaves: \_id, nome, preco, descricao, quantidade).

2. `src/main.jsx`
   - Configuração do ponto de entrada envolvendo a aplicação no `<BrowserRouter>`.

3. `src/layouts/RootLayout.jsx`
   - Componente de Layout Shell contendo um `<header>` com um `<nav>`.
   - Para o espaço do usuário (`/app`), o nav deve conter links criados com `<NavLink>` para: `/app` (Dashboard) e `/app/produtos` (Produtos). Utilize a prop de callback do NavLink para indicar o estado ativo (apenas texto/lógica simples, sem CSS).
   - Um elemento `<main>` contendo o componente `<Outlet />` para renderizar o conteúdo dinâmico.

4. `src/layouts/AuthLayout.jsx` (Layout Minimalista de Autenticação)
   - Componente de layout simples e minimalista exclusivo para telas públicas de acesso (`/login`).
   - NÃO deve conter `<header>` nem `<nav>`. Contém apenas o elemento `<main>` com o `<Outlet />` para exibir o formulário de login isoladamente.

5. `src/layouts/ProtectedRoute.jsx` (Gate de Autenticação)
   - Componente wrapper/layout de proteção que atua como Gate para todo o User Space (`/app/*`).
   - Deve utilizar `<Outlet />` para renderizar as rotas filhas caso o utilizador esteja autenticado (simulado por uma variável/flag para futura integração com API/AuthContext).
   - Caso não esteja autenticado, redireciona o utilizador para a rota `/login` utilizando o componente `<Navigate />`.

6. `src/pages/Home.jsx`
   - Landing page pública do ERP com um <h1> de apresentação e links de acesso para `/login` e `/app`.

7. `src/pages/Dashboard.jsx`
   - Painel inicial do usuário autenticado no User Space (`/app`).
   - Exibe mensagem de boas-vindas ao painel administrativo e resumo/links rápidos.

8. `src/pages/Produtos.jsx`
   - Listagem de produtos no User Space (`/app/produtos`).
   - Importa o `mockProdutos`.
   - Mapeia os produtos e exibe nome, preço e um `<Link>` para a rota de detalhes (`/app/produtos/${produto._id}`).

9. `src/pages/ProdutoDetalhes.jsx`
   - Detalhes do produto (`/app/produtos/:id`).
   - Utiliza o hook `useParams()` para capturar o `id` da URL.
   - Busca o produto correspondente no `mockProdutos`.
   - Exibe as informações do produto (\_id, nome, descricao, quantidade, preco) ou mensagem de "Produto não encontrado".
   - Inclui um `<Link>` para retornar à lista de produtos (`/app/produtos`).

10. `src/pages/Login.jsx`
    - Formulário com campos de e-mail e palavra-passe.
    - Utiliza o hook `useNavigate()` para redirecionar o utilizador para a área logada (`/app`) após a submissão do formulário (`onSubmit`).

11. `src/pages/NotFound.jsx`
    - Componente para a rota 404 (Página não encontrada).

12. `src/App.jsx`
    - Mapeamento de todas as rotas usando `<Routes>` e `<Route>`:
      - Rota Landing Page: `path="/" element={<Home />}`.
      - Rota de Autenticação: `path="/login"` utilizando `AuthLayout` (sem header/nav) e renderizando `Login`.
      - Rota User Space ERP (Protegida por Gate): `path="/app"` utilizando `element={<ProtectedRoute />}` que envolve o `RootLayout` (com header e nav), contendo as rotas filhas:
        - `index`: `Dashboard` (`/app`)
        - `produtos`: `Produtos` (`/app/produtos`)
        - `produtos/:id`: `ProdutoDetalhes` (`/app/produtos/:id`)
      - Rota 404: `path="*" element={<NotFound />}`.

Por favor, forneça o código de cada arquivo de forma limpa, organizada e sem nenhum código de estilo.
```
