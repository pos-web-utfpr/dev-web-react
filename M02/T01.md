# Desenvolvimento de Aplicações Web Dinâmicas e Interativas

## Módulo 2: Gerenciamento de Estado e Ciclo de Vida

**Objetivo de Aprendizagem**: Dominar o fluxo de dados unidirecional e a reatividade através dos Hooks fundamentais para criar interfaces dinâmicas.

## Tópico 1: Gerenciamento de Estado

- O fluxo de renderização: a árvore de componentes
- Imutabilidade
- Hook useState
- O gatilho do render: mudança de estado
  - Interatividade com o usuário: o evento onPress
- Capturando dados: input, value e onChange
- Tipagem segura de estados
  - Inferência de tipos
  - Tipagem múltipla
