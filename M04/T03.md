## Exemplos de uso

**Instalação da biblioteca Zod**:

```bash
yarn add zod
```

### 1. Exemplo Minimalista com `.parse()` (`CitySchema.ts`)

**Schema (`src/schemas/CitySchema.ts`):**

```typescript
import { z } from "zod";

export const CitySchema = z.object({
  id: z.number(),
  name: z.string(),
});

export type CitySchema = z.infer<typeof CitySchema>;
```

**Uso em TypeScript com `.parse()`:**

```typescript
import { CitySchema } from "./schemas/CitySchema";

// Dado de origem desconhecida (ex: payload de API ou formulário)
const data: unknown = { id: 1, name: "Curitiba" };

// .parse() valida os dados e retorna o objeto tipado como CitySchema (lança ZodError se for inválido)
const city: CitySchema = CitySchema.parse(data);

console.log(city.name); // "Curitiba"
```

### 2. Schema de Formulário de Login (`LoginSchema.ts`)

**Schema (`src/schemas/LoginSchema.ts`):**

```typescript
import { z } from "zod";

export const LoginSchema = z.object({
  email: z.email("Formato de e-mail inválido"),
  password: z.string().min(4, "A senha deve ter no mínimo 4 caracteres"),
});

export type LoginSchema = z.infer<typeof LoginSchema>;
```

**Uso com Mantine `useForm` e `zodResolver`:**

```typescript
import { useForm, zodResolver } from "@mantine/form";
import { LoginSchema } from "../schemas/LoginSchema";

const form = useForm<LoginSchema>({
  initialValues: {
    email: "",
    password: "",
  },
  validate: zodResolver(LoginSchema),
});
```

### 3. Schema de Produto Único e Parse de API (`ProductSchema.ts`)

**Schema de um Produto Único (`src/schemas/ProductSchema.ts`):**

```typescript
import { z } from "zod";

export const ProductSchema = z.object({
  _id: z.string(),
  nome: z.string(),
  preco: z.number(),
  descricao: z.string(),
  quantidade: z.number(),
});

export type ProductSchema = z.infer<typeof ProductSchema>;
```

**Uso em Requisição HTTP GET (`z.array(ProductSchema).parse(...)`):**

```typescript
import { z } from "zod";
import { api } from "../services/api";
import { ProductSchema } from "../schemas/ProductSchema";

async function fetchProducts() {
  const response = await api.get("/produtos");

  // Substituição do cast 'as Produto[]' pelo parse do array de schemas no ponto de chamada
  const products = z.array(ProductSchema).parse(response.data.produtos);

  return products;
}
```
