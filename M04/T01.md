**Objetivo de Aprendizagem**: Conectar aplicações React ao mundo real através de requisições HTTP, tratando estados de carregamento, erro e sucesso de forma reativa.

## Tópico 1: Consumo de APIs

  - Interceptores de requisição e resposta
  - Transformação automática de JSON
  - Sintaxe simples e elegante
- Configuração da biblioteca e a instância centralizada
- Estrutura de requisições GET/POST/PUT/DELETE
- Estados de Loading e Error

## Exemplos de Uso

### GET minimalista:

```js
import axios from 'axios';
import { useEffect, useState } from 'react';

type User = {
  id: number;
  name: string;
};

function App() {
  const [users, setUsers] = useState<User[]>([]);

  useEffect(() => {
    axios.get<User[]>('https://jsonplaceholder.typicode.com/users')
      .then(response => setUsers(response.data))
      .catch(error => console.error('Erro:', error));
  }, []);

  return (
    <ul>
      {users.map(user => <li key={user.id}>{user.name}</li>)}
    </ul>
  );
}
```

### Tratamento de Loading e Erro

```js
import axios from 'axios';
import { useEffect, useState } from 'react';

type User = {
  id: number;
  name: string;
};

function App() {
  const [users, setUsers] = useState<User[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);

  useEffect(() => {
    axios.get<User[]>('https://jsonplaceholder.typicode.com/users')
      .then(response => setUsers(response.data))
      .catch(error => setError(error))
      .finally(() => setLoading(false));
  }, []);

  if (loading) return <p>Carregando...</p>;
  if (error) return <p>Erro: {error.message}</p>;

  return (
    <ul>
      {users.map(user => <li key={user.id}>{user.name}</li>)}
    </ul>
  );
}
```

### Prompt 1: Configuração Centralizada da Axios

```markdown
Vamos PLANEJAR a integração da Axios no projeto do App Supermercado (ServeRest UI).

Atue como um desenvolvedor Front-end especialista em React. Preciso que você realize a instalação da biblioteca Axios e crie uma instância centralizada de HTTP para a nossa aplicação.

Requisitos:

1. Instale a biblioteca `axios`.
2. Crie o arquivo `src/services/api.ts` e exporte uma instância configurada via `axios.create()`.
3. Configure a `baseURL` apontando para a API ServeRest (`https://serverest.dev`).
4. Configure o cabeçalho padrão (`headers`) com `'Content-Type': 'application/json'`.

ATENÇÃO / RESTRIÇÕES:

- NÃO configure token de autenticação nem interceptores (interceptors) nesta etapa (isso será feito em aula posterior).
- NÃO utilize ou importe a instância da Axios em nenhuma tela ou componente neste momento (o consumo nas telas será feito no próximo prompt).
```

```markdown

Atue como um desenvolvedor Front-end especialista em React. Preciso que você substitua a simulação com dados mockados na página `Produtos.tsx` por uma requisição HTTP real (método GET).
```
