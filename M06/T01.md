# Desenvolvimento de Aplicações Web Dinâmicas e Interativas

## Módulo 6: Pipelines CI/CD e Visão Profissional

**Objetivo de Aprendizagem**: Conhecer e aplicar ferramentas e processos que viabilizem a entrega contínua de aplicações web, compreendendo o papel do desenvolvedor no ecossistema e mercado profissional.

## Tópico 1: Introdução ao CI (Integração Contínua)

- Workflow com Github Actions:
  - checkout do código → instalar dependências → rodar testes unitários → rodar testes E2E
- Proteção de branch
- Discussão sobre os resultados do workflow no GitHub

## Prompts da Aula

**Prompt 1**:

```markdown
Crie um único workflow simples do GitHub Actions para a aplicação de supermercado na raiz do repositório (`.github/workflows/ci.yml`).

O workflow deve ser disparado nos eventos de `push` e `pull_request` para a branch `main`.

Monte o pipeline de testes de forma simples e direta, estruturado em etapas bem definidas:
1. **Checkout do repositório**: utilizar `actions/checkout@v4`.
2. **Configuração do ambiente Node.js**: utilizar `actions/setup-node@v4` (Node 24.x / LTS) com cache de dependências via `yarn`.
3. **Instalação das dependências**: executar `yarn install --frozen-lockfile`.
4. **Execução dos Testes Unitários**: rodar o comando `yarn test:run` (Vitest).
5. **Execução dos Testes E2E**: instalar os navegadores do Playwright (`yarn playwright install --with-deps`) e rodar `yarn test:e2e`.

Forneça o código do arquivo YAML bem comentado, explicando brevemente o propósito de cada etapa.
```
