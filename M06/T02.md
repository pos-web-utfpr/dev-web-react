## Tópico 2: Pipeline CD (Entrega Contínua)

- Deploy de aplicação no GitHub Pages
  - SPA e configurações específicas do React
- Workflow com Github Actions:
  - build da aplicação → deploy no GitHub Pages

## Prompts da Aula

> **Pré-requisito no GitHub (Configuração Inicial)**:
> Antes de executar o workflow de CD pela primeira vez, ative a publicação via GitHub Actions no repositório:
> 1. No repositório do GitHub, acesse **Settings** > **Pages**.
> 2. Em **Build and deployment** > **Source**, altere a opção para **GitHub Actions**.

**Prompt 1**:

```markdown
Crie um workflow de Continuous Deployment (CD) do GitHub Actions para a aplicação de supermercado na raiz do repositório (`.github/workflows/cd.yml`), responsável por realizar o build e o deploy da aplicação no GitHub Pages.

O workflow deve ser disparado no evento de `push` para a branch `main` (e permitir disparo manual via `workflow_dispatch`).

Estruture o pipeline de deploy em etapas bem definidas:
1. **Configuração de Permissões e Concorrência**: definir permissões para o GitHub Pages (`contents: read`, `pages: write`, `id-token: write`) e gerenciar a concorrência para deploy no GitHub Pages.
2. **Checkout do repositório**: utilizar `actions/checkout@v4`.
3. **Configuração do ambiente Node.js**: utilizar `actions/setup-node@v4` (Node 24.x / LTS) com cache de dependências via `yarn`.
4. **Instalação das dependências**: executar `yarn install --frozen-lockfile`.
5. **Build da Aplicação e Suporte a SPA**: rodar `yarn build` definindo a variável de ambiente `VITE_API_URL` apontando para a API remota (`https://serverest.dev`) e criar o arquivo `404.html` (copiando `dist/index.html` para `dist/404.html`) para suporte ao roteamento client-side no GitHub Pages.
6. **Configuração e Upload do Artefato**: utilizar `actions/configure-pages@v5` e `actions/upload-pages-artifact@v3` configurando o caminho da pasta de build (`supermercado/dist`).
7. **Deploy no GitHub Pages**: utilizar `actions/deploy-pages@v4` para publicar os arquivos.

Forneça o código do arquivo YAML bem comentado, e explique brevemente a estratégia do `404.html` e as configurações de SPA necessárias no React/Vite (como a propriedade `base` no `vite.config.ts` e suporte ao roteamento).
```
